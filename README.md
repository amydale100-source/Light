# 🪽 網頁版互動手燈 - 飛越台灣
> 一款純前端（HTML5 / CSS3 / JavaScript）打造的網頁版互動虛擬手燈。專為活動應援設計，具備流暢的動畫與高質感的夜間模式視覺體驗。

## 🌟 專案特色與亮點
* **精確台灣意象**：核心球體嵌入精細的台灣地圖 SVG，並搭配夜間深色調（Slate-900）的質感外框。
* **動態青鳥應援**：啟動後會觸發細緻的 CSS 貝氏曲線動畫（`cubic-bezier`），讓象徵自由的青鳥以優雅的弧線、旋轉與縮放特效飛越台灣。
* **柔和色彩美學**：在七彩呼吸模式中，特別採用 **HSL 色彩空間**（飽和度 85%、亮度 80%），確保燈光漸變時色彩柔和不刺眼，打造夢幻的棉花糖/馬卡龍粉嫩色系。

## 🚀 核心功能 (Features)
本手燈支援三段式循環切換模式（Off ➔ Static ➔ RGB Flow）：
1. ⚪ **關閉模式 (Power Off)**：低調沉穩的深色球體。
2. 🟡 **常亮模式 (Static Mode)**：手燈發出極致白光，並提供「自訂色彩」功能。點擊把手上的 RGB 按鈕即可喚起調色盤，自由定義你的應援色。
3. 🌈 **七彩呼吸模式 (Pastel RGB Breathing)**：自動循環播放柔和的七彩漸變呼吸燈，並伴隨文字微光閃爍效果（`textBreath`）。

## 🛠️ 使用技術 (Tech Stack)
* **前端架構**：Vanilla JavaScript (ES6+), HTML5, CSS3
* **樣式整合**：Tailwind CSS (透過 CDN 引入)
* **動畫技術**：CSS `@keyframes`（包含 `birdFly`, `textBreath`, `rgbBreathMode`, `float` 飄浮效果）

## 📦 檔案結構 (Project Structure)
* `index.html` - 包含所有互動邏輯（DOM 事件監聽、模式切換）、內嵌 SVG 以及 Tailwind 樣式設計的單一網頁檔案（隨開隨用，極致輕量）。

## ⚙️ 快速開始 (Getting Started)
由於本專案為 100% 純前端開發，不需要安裝任何後端環境或伺服器。
1. 下載或複製 `index.html` 到你的電腦。
2. 雙擊開啟 `index.html`（或使用瀏覽器開啟）。
3. 點擊網頁下方的 **「Power On」** 按鈕，或者**直接點擊手燈球體**，即可開始體驗！

## 📈 開發心得與技術收穫
* **CSS 動態美學**：深入實作了多組動畫並存的複雜情境，利用 `pointer-events: none` 防止動畫元件干擾使用者的點擊操作。
* **行動端觸控優化**：在 Body 標籤加入 `touch-action: manipulation`，有效阻斷智慧型手機雙擊縮放的延遲，讓手機使用者的點擊反饋更即時。
